שם התג ב-GTM הוא רק לך. שדה Event Name הוא לגוגל — ולו יש חוקים נוקשים. שם שגוי = אירוע שנעלם.

שני שדות, שתי מטרות שונות לחלוטין

שם התג (למעלה ב-GTM): רק לצורך ארגון אישי — כתוב מה שנוח לך, בכל שפה.

האופציה שכבר מסומנת — מה היא עושה?

כשמסמנים Send Ecommerce Data → Data Layer, GTM לא מדווח לGA4 רק את שם האירוע. הוא מציץ בתוך קוד האתר ברגע הרכישה, אוסף את כל מידע סל הקניות — ושולח הכל ביחד עם התג.

🟢 לניתוח אנליטי — מצוין

GA4 — דאטה עמוקה לאקספלורציות

תוכל לשאול ב-Explorations: "מי שקונה מעל 1000 ש"ח — אילו מוצרים הוא הכי אוהב?". בלי הנתונים האלה השאלה הזו לא ניתנת לתשובה.

📌

השאר את התיבה מסומנת כפי שהיא. רק ודא ששדה ה-Event Name תוקן (למשל purchase_over_1000 ללא רווחים ו-ללא >) — ואתה מוכן לחלוטין ללחוץ על Save.

🏷️

תזכורת — שם התג ב-GTM הוא חופשי לגמרי

בניגוד ל-Event Name, שם התג עצמו (הכותרת שרואים ברשימת התגים ב-GTM) הוא לשימוש פנימי בלבד. כתוב בו בעברית, עם סימנים, עם תיאור מלא — GA4 לעולם לא רואה את זה.

למשל: שם התג יכול להיות "GA4 — רכישה מעל 1000 ₪ (VIP)" ובו זמנית שדה ה-Event Name יהיה purchase_over_1000. שניהם נכונים, כל אחד בשדה שלו.
