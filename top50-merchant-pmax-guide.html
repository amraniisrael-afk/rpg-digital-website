Google Analytics — שליפת 50 המוצרים הנמכרים ביותר
  • 1
    כנס ל-Google Analytics 4 Reports → Monetization → Ecommerce purchases
  • 2
    הגדר טווח תאריכים בחר את התקופה הרלוונטית (מומלץ: 90 ימים אחרונים)
  • 3
    מיין לפי Items purchased לחץ על העמודה כדי למיין מהגבוה לנמוך
  • 4
    הצג 50 שורות בתחתית הטבלה שנה Rows per page ל-50
  • 5
    ייצא ל-Google Sheets / CSV לחץ על אייקון ה-Export בפינה הימנית למעלה של הטבלה
  • 6
    הכן את הקובץ הסופי השאר רק שתי עמודות: id ו-custom_label_4 — הוסף ידנית את הערך Top_50 לכל שורה
# מבנה הקובץ הסופי
id custom_label_4
7220 Top_50
27025 Top_50
24639 Top_50
ה-Item ID באנלטיקס חייב להיות זהה בדיוק ל-Product ID במרצ'נט סנטר. בדוק מוצר אחד לפני העלאה.

Google Merchant Center — עדכון Custom Label דרך Supplemental Feed
  • 1
    המר את הקובץ ל-TSV Google Sheets → File → Download → Tab-separated values (.tsv)
    שים לב: מרצ'נט לא מקבל CSV רגיל
  • 2
    Products → Data sources → Supplemental sources → Add supplemental source בחר: File → Upload a file from your computer
  • 3
    העלה את קובץ ה-TSV סמן "Upload as test" לבדיקה ראשונה לפני הפעלה אמיתית
  • 4
    בחר Primary source בחר את ה-XML הראשי שלך מהרשימה
  • 5
    וודא תוצאות תקינות Matched products = 50 | Attribute names = All recognized | No issues found
  • 6
    לחץ "Apply update" הלייבל יתעדכן על כל 50 המוצרים תוך מספר דקות
לעדכון עתידי: לחץ Update באותו supplemental feed והעלה קובץ TSV חדש — אין צורך ליצור feed חדש.
3
Google Ads — PMAX Best Practices לקמפיין Top 50
  • 1
    יצירת Asset Group ממוקד בקמפיין PMAX → Asset Groups → Listing Groups → סנן לפי Custom label 4 = Top_50
  • 2
    הפרד בין Top 50 לשאר המוצרים צור Asset Group נפרד לשאר ("Everything else") עם תקציב/bid שונה
Best Practices לניהול הקמפיין
תקציב ו-Bidding
  • השתמש ב-Maximize conversion value
  • הגדר tROAS רק לאחר 30-50 המרות
  • אל תשנה bid strategy בשבועיים הראשונים
  • תקציב יומי מינימום: x3 מה-CPA הממוצע
Assets — תמונות וטקסטים
  • מינימום 3-5 תמונות בכל פורמט (1:1, 4:1, 1.91:1)
  • 15 כותרות + 5 תיאורים שונים
  • הוסף לפחות סרטון אחד (YouTube)
  • שמות מוצרים ספציפיים בכותרות
Audience Signals
  • הוסף רשימת לקוחות קיימים (Customer Match)
  • רשימת Cart Abandoners מ-GA4
  • In-market segments רלוונטיים לקטגוריה
  • Remarketing מהאתר (30/60/90 יום)
מעקב וניטור
  • בדוק Insights בכל שבוע (לא לנגוע בהגדרות)
  • עקוב אחרי Asset performance (Low/Good/Best)
  • החלף assets עם דירוג Low לאחר 2 שבועות
  • בדוק Search themes שגוגל מוסיף אוטומטית
מה לא לעשות
  • לא לשנות תקציב יותר מ-20% בכל פעם
  • לא לעצור קמפיין ולהפעיל מחדש — מאפס למידה
  • לא ליצור יותר מדי Asset Groups (5-10 מקסימום)
  • לא לבדוק Search Terms בתדירות גבוהה מדי
אופטימיזציה שוטפת
  • עדכן את רשימת Top 50 כל חודש מ-GA4
  • הוסף Custom Label נוסף לעונתיות / מבצעים
  • בדוק Product level performance דרך Merchant
  • השתמש ב-Supplemental Feed לעדכונים קבועים
טיפ: PMAX צריך לפחות 6 שבועות learning period לפני שמוציאים מסקנות. אל תשנה הגדרות משמעותיות בתקופה הזו.
