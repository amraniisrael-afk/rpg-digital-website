# מודעות לידים לקרוסלה בדף הבית

קובצי המקור של 4 המודעות בקרוסלת ההירו (l1–l4.webp בתיקיית "תמונות קרוסלה").
אלה מודעות לדוגמה שעוצבו לאתר, לא עבודות ללקוחות אמיתיים. כדאי להחליף בעבודות אמיתיות כשיהיו.

רינדור מחדש (1000×1250):
```
chrome --headless=new --window-size=1000,1250 --virtual-time-budget=6000 --screenshot=out.png l1-realestate.html
```
ואז המרה ל-webp באיכות 82.
