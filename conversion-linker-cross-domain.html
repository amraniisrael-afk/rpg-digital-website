2
הגדר את שדות Linker Options בדיוק
הגדרת שדות

כל שדה בתג משפיע על איך ה-gclid מועבר בין האתרים. להלן הסבר לכל שדה:

שדהערך מומלץהסבר
Enable linking on all page URLs ❌ לא מסומן מוסיף gclid לכל URL באתר — לא נחוץ בד"כ
Enable linking across domains ✅ מסומן מאפשר העברת gclid בין דומיינים שונים
Auto Link Domains site-b.com,checkout.com רשימת דומיינים של אתר B — מופרדים בפסיק
Decorate Forms False True רק אם עוברים דרך Form submission
URL Position Query Parameter מוסיף gclid כ-?gclid= ב-URL (סטנדרט)
Accept incoming linker parameters ✅ מסומן על אתר B לאשר קבלת הפרמטרים מאתר A
⚠️ Fragment vs Query: URL Position = Query Parameter שולח ?gclid=123. Fragment שולח #gclid=123 — Fragment לא נשלח לשרת ולא נקרא ב-Server Side. בד"כ Query Parameter הוא הבחירה הנכונה.
3
הוסף Conversion Linker גם ב-GTM של אתר B
GTM — אתר B

לא מספיק להגדיר רק באתר A. אתר B חייב גם הוא Conversion Linker עם "Accept incoming linker parameters" מסומן — כדי לקרוא את ה-gclid שהגיע ב-URL וליצור ממנו קוקי _gcl_aw.

שדהאתר A (שולח)אתר B (מקבל)
Enable linking across domains ✅ חובה אופציונלי
Auto Link Domains domain-b.com domain-a.com (אם דו-כיווני)
Accept incoming linker parameters אופציונלי ✅ חובה
Trigger All Pages All Pages
הלוגיקה: אתר A מוסיף את ה-gclid ל-URL → אתר B קורא אותו ויוצר קוקי _gcl_aw → תג ה-Conversion Tracking באתר B קורא את הקוקי → ההמרה מיוחסת נכון.
4
בדוק שהקוקי _gcl_aw נוצר — DevTools Application
בדיקה

לחץ על מודעת גוגל (או הוסף ?gclid=TEST123 ל-URL ידנית) → פתח DevTools → Application → Cookies → חפש _gcl_aw.

✅ מה לבדוק:
• קוקי _gcl_aw קיים = Conversion Linker עובד
• ערכו: GCL.<timestamp>.<gclid> — גלה את ה-gclid המקורי מה-URL
• הדומיין: .yourdomain.com (עם נקודה = כל subdomain)
• Expires: ~90 יום מתאריך הקליק
⚠️ אם _gcl_aw לא קיים — בדוק: (1) Conversion Linker נפרס ב-GTM? (2) הטריגר = All Pages? (3) ה-URL מכיל gclid?
5
בדוק שה-gclid עובר בלינקים בין האתרים
בדיקה מתקדמת

לחץ על לינק שמוביל מאתר A לאתר B → בדוק את ה-URL של אתר B — הוא חייב להכיל ?gclid= (או כ-Query Parameter בסוף).

URL תקין באתר B ייראה כך:
https://site-b.com/checkout?gclid=1234567890&gclsrc=aw.ds

הפרמטר gclsrc=aw.ds מאשר שהמקור הוא Google Ads (aw = AdWords, ds = DoubleClick Search).
💡 אפשר לבדוק ב-GTM Preview של אתר B: פתח Debug → בדוק אם הטריגר של Conversion Linker יורה → ב-Variables תראה gclid עם ערך אמיתי.
