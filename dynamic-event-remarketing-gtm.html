1
הפעל "Send dynamic remarketing event data"
Google Ads Tag

בתג ה-Google Ads Remarketing ב-GTM, סמן V את האפשרות "Send dynamic remarketing event data". פעולה זו פותחת את 3 השדות הדינמיים: Event Name, Event Value ו-Event Items.

📸 צילום מסך — GTM: תצורת תג Google Ads Dynamic Event Remarketing
מה רואים בצילום המסך:
• Tag Type: Google Ads Remarketing
• Conversion ID: 17925300294
• ✅ Google tag found in this container (GTAG D9SHOP)
• ✅ Send dynamic remarketing event data — מסומן
• Triggering: Ecommerce All Events | Regex
2
הגדר Event Name — המשתנה {{Event}}
GTM Variable

בשדה Event Name חיבר את המשתנה {{Event}} — המשתנה המובנה של GTM שתופס את שם האירוע הנוכחי. גוגל מזהה אוטומטית את הערכים הסטנדרטיים ומשתמשת בהם לסיווג המוצרים ברימרקטינג.

שם האירועמה גוגל מזהה
view_itemצפייה במוצר
add_to_cartהוספה לסל
begin_checkoutהתחלת תשלום
purchaseרכישה
💡 שימוש ב-{{Event}} אחד במקום 4 תגים נפרדים — GTM מושך אוטומטית את שם האירוע מכל push לדאטאליירר.
3
חבר Event Value — {{Ecommerce Price Value}}
GTM Variable

בשדה Event Value חיבר את המשתנה {{Ecommerce Price Value}} שמושך את ערך הרכישה מהדאטאליירר. גוגל משתמשת בערך זה לחישוב רווחיות מודעות הרימרקטינג ולאופטימיזציית Value-Based Bidding.

שדה ב-GTMמשתנהמקור הנתון
Event Value{{Ecommerce Price Value}}ecommerce.value מה-DataLayer
איך המשתנה בנוי: ב-GTM → Variables → צור Data Layer Variable עם שם ecommerce.value (שים לב לנקודה — זהו nested object).
4
שלח Event Items — {{Ecommerce Items}}
GTM Variable

בשדה Event Items חיבר את המשתנה {{Ecommerce Items}} שמושך את מערך המוצרים המלא מה-DataLayer. זה מה שמאפשר לגוגל להציג את המוצר הספציפי שהמשתמש ראה — עם תמונה, שם ומחיר — במודעת הרימרקטינג.

שדה ב-GTMמשתנהמקור
Event Items{{Ecommerce Items}}ecommerce.items[] מה-DataLayer
⚠️ ה-ID שעובר ב-items[].item_id חייב להיות זהה ל-ID שמופיע ב-Google Merchant Center — אחרת גוגל לא תוכל לשייך את המוצר.
5
צור טריגר Regex חכם לכל אירועי האיקומרס
GTM Trigger

במקום ליצור 4 טריגרים נפרדים — בנה טריגר אחד מסוג Custom Event עם Regex שמכסה את כולם.

שדהערך
שם הטריגרEcommerce All Events | Regex
Trigger TypeCustom Event
Event Nameview_item|add_to_cart|begin_checkout|purchase

💡 הטריגר Ecommerce All Events | Regex נראה בצילום המסך מתחת ל-Triggering — כתום עם סמל <> שמסמן Custom Event.
6
אל תשתמש ב-"All Pages" לתג הדינמי
שגיאה נפוצה

טעות נפוצה: להפעיל את התג הדינמי על כל הדפים. הבעיה — בדפים ללא מוצרים השדות יהיו ריקים וגוגל תקבל נתונים שבורים.

🚫 לא לעשות: Trigger = All Pages על התג הדינמי
לעשות: Trigger = Ecommerce All Events | Regex בלבד

כך התג יורה רק כשיש מוצר בדאטאליירר — ולא ישלח נתונים ריקים.
7
שמור תג רימרקטינג בסיסי נפרד על All Pages
תג נוסף

בנוסף לתג הדינמי — שמור תג רימרקטינג בסיסי (ללא Send dynamic remarketing data) שיורה על כל הדפים. זה צובע את כל המבקרים באתר ומאפשר קהלי רימרקטינג כלליים גם למי שלא הגיע לדף מוצר.

תגSend Dynamic DataTriggerמטרה
Google Ads Dynamic Remarketing✅ כןEcommerce Events | Regexרימרקטינג לפי מוצר
Google Ads Basic Remarketing❌ לאAll Pagesצביעה כללית
8
בדוק ב-GTM Preview שהתג נורה והמשתנים מקבלים ערכים
בדיקה

פתח GTM Preview, בצע פעולת view_item או purchase באתר, ווודא שהתג "Google Ads Dynamic Event Remarketing" נורה ושכל שלושת המשתנים ({{Event}}, {{Ecommerce Price Value}}, {{Ecommerce Items}}) מקבלים ערכים אמיתיים.

✅ ב-Tag Assistant: לחץ על התג → Variables → תראה:
• {{Event}} = view_item (או purchase)
• {{Ecommerce Price Value}} = 29.99 (מחיר אמיתי)
• {{Ecommerce Items}} = [{...}] (מערך מוצרים)
9
ודא שה-ID מהאתר זהה ל-ID ב-Merchant Center
אימות קריטי

הצעד הקריטי ביותר: ה-item_id שעובר ב-DataLayer חייב להיות זהה בדיוק ל-ID שמוגדר ב-Google Merchant Center. חוסר התאמה = גוגל לא מציגה תמונות מוצר ורימרקטינג לא עובד.

🔍 איך לבדוק: בדאטאליירר של view_item → items[0].item_id (לדוגמה: 30288)
ב-Merchant Center → Products → חפש את המוצר → שדה ID חייב להיות זהה: 30288

שים לב: Shopify משתמשת לעיתים ב-Variant ID, לא ב-Product ID — בדוק מה שולח ה-DataLayer.
💡 אחרי פרסום ב-GTM, לך ל-Google Ads → Audience Manager → ודא שרשימות הרימרקטינג הדינמיות מתחילות להצטבר תוך 24-48 שעות.
