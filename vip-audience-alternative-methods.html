1

GTM — אירוע מותאם אישית

השיטה שיישמנו — מעולה, אבל דורשת עדכון GTM לכל שינוי בסף

יצרנו טריגר Some Custom Events שמפעיל תג GA4 בשם purchase_over_1000 רק כשהעסקה חוצה את הסף. האירוע הייחודי הזה מגיע ל-GA4 ומשם לקמפיינים.

מתי זה הכי נכון: כשרוצים אירוע נפרד ומובחן בדוחות GA4, עם שם שקל לזהות. הדאשבורד נשאר נקי כי ה-VIP מוגדר כאירוע בפני עצמו.

החיסרון היחיד: שינוי הסף (מ-1000 ל-1500 ש"ח) מצריך כניסה ל-GTM, עדכון הטריגר, ו-Publish מחדש.

2

סינון ישיר בתוך מערכות הקהלים

אירוע purchase רגיל + פרמטר value — בלי לגעת ב-GTM

מאחר ש-Send Ecommerce Data מסומן, הפרמטר value (סכום העסקה) כבר זורם עם כל אירוע purchase רגיל לשתי המערכות. כל מה שנשאר — להגיד למערכת הקהלים לסנן לפיו.

📊 Google Analytics 4

קהל חדש עם פרמטר value

  • 1
    יוצרים קהל חדש ב-GA4 — Admin → Audiences → New audience
  • 2
    בוחרים את האירוע הסטנדרטי purchase (לא אירוע מותאם)
  • 3
    לוחצים על Add parameter → מחפשים value
  • 4
    מגדירים: greater than → 1000
  • 5
    שומרים — הקהל מתחיל לצבור מיד
📘 Meta (Facebook)

קהל מותאם + Refine by value

  • 1
    Audiences → Create → Custom Audience → Website
  • 2
    בשדה האירוע בוחרים Purchase (הסטנדרטי)
  • 3
    לוחצים על Refine by → בוחרים URL/Parameter
  • 4
    בוחרים פרמטר value → greater than → 1000
  • 5
    שומרים — הקהל מוכן לשימוש בקמפיינים
💡

היתרון הגדול: גמישות מוחלטת — לשנות את הסף מ-1,000 ל-1,500 ש"ח לוקח שני קליקים ישירות בממשק הקהלים, בלי לגעת בקוד או ב-GTM. אין צורך ב-Publish, אין ריצה לדב.

3

Customer Match — העלאת רשימת לקוחות

דאטה מהחנות ישירות למערכת — חסין לחוסמי פרסומות ולבעיות פיקסל

במקום להסתמך על פיקסל שיזהה את הגולש בזמן אמת, אתה פועל "אופליין" — מייצא את הדאטה שכבר קיים במערכת הניהול של החנות ומעלה אותו ישירות לגוגל או לפייסבוק.

1

יצוא מהחנות

נכנסים ל-Shopify / WooCommerce / מערכת הניהול → מפיקים דוח לקוחות מסונן לפי רכישה בודדת מעל 1,000 ש"ח (או לפי LTV גבוה — סכום מצטבר לאורך זמן). הקובץ יכיל: כתובת מייל + מספר טלפון.

2

כניסה למנהל הקהלים

Google Ads: Tools → Audience Manager → + → Customer list
Meta: Audiences → Create → Custom Audience → Customer list

3

העלאת הקובץ

מעלים את ה-CSV. המערכת מצפינה (Hash) את המיילים ומספרי הטלפון ומשווה אותם למשתמשים אמיתיים בפלטפורמה.

4

שימוש בקמפיינים

הקהל מוכן בתוך כמה שעות — אפשר להשתמש בו לרימרקטינג, Lookalike (Meta) או Audience Signal (PMax).

🎯 Google Ads

נקרא Customer Match. דורש חשבון עם היסטוריה טובה (Ads Policy). קהל תקף גם לקמפייני Search, Shopping ו-YouTube.

📘 Meta

נקרא Customer List. אחוז ה-Match (התאמה) בדרך כלל 50–70%. כל מאצ' = משתמש אמיתי בקהל.

🛡️

היתרון הגדול: חסינות מוחלטת — חוסמי פרסומות, מחיקת קוקיז, הגבלות iOS של אפל, GTM שהתקלקל. כלום לא משפיע. הדאטה מגיע ישירות מהסליקה שלך ולכן הוא המדויק ביותר מבין השלושה.
