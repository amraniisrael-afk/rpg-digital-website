בדוק שה-DataLayer שולח את האימייל
GTM Preview

לפני כל הגדרה בטמ — וודא שאירוע ה-purchase מכיל את השדה user_email עם הערך האמיתי. פתח GTM ב-Preview Mode, בצע רכישה, לחץ על האירוע purchase ובדוק ב-API Call.

DataLayer — API Call dataLayer.push({

  user_email: "john@doe.com", // ← חשוב: חייב להיות פה

    discount_value: "10.00",
    currency: "EUR",
    value: "29.99",
    transaction_id: "no12345-91129",
    items: [{
      item_name: "Awesome green T-shirt",
      item_id: "agt1",
      price: "29.99"
    }]
  }
})
📸 צילום מסך — GTM Preview: אירוע purchase עם user_email
💡 שים לב: ב-GTM Preview רואים את user_email מודגש בכחול — זה אומר שה-dataLayer שלח אותו בהצלחה לפני הטריגר.

3
צור משתנה: User Provided Data Variable
GTM Variables

ב-GTM → Variables → New — צור משתנה מסוג User-Provided Data. זה המשתנה שמארז את כל נתוני המשתמש ומכין אותם בפורמט שגוגל מצפה לו (כולל ה-HASH).

שדה ערך
שם המשתנהUser Provided Data Variable
Variable TypeUser-Provided Data
TypeManual configuration ✔
Email{{User Email - E.C}}
PhoneNot set
Name and AddressNot set
📸 צילום מסך — User Provided Data Variable עם {{User Email - E.C}}
למה Manual ולא Automatic? — Automatic Collection מנסה לתפוס שדות טופס לפי סלקטורים. Manual מאפשר לנו לשלוט בדיוק על מה שנשלח ולהתחבר ישירות ל-DataLayer בלי תלות ב-DOM.
4
הוסף ל-Google Ads Conversion Tag
Google Ads Tag

פתח את תג ה-Conversion הקיים (Google Ads | Purchase | Conversion), גלול למטה ל-Event Parameters והוסף פרמטר חדש — זה השלב שמחבר את כל ההגדרה לגוגל.

שדה ערך
Event Settings VariableNone
Event Parameteruser_data
Value{{User Provided Data Variable}}
📸 צילום מסך — Google Ads Conversion Tag עם פרמטר user_data
⚠️ שם הפרמטר חייב להיות user_data בדיוק — זהו פרמטר Known ש-Google Ads מזהה אוטומטית כ-Enhanced Conversion data.
5
אמת עם EC Assist
אימות

התוסף EC Assist לכרום מאפשר לבדוק בדיוק מה נשלח לגוגל. לחץ Inspect → בחר את ה-Conversion → תראה את האימייל המוצפן ואת אישור "Email Address Observed".

📸 צילום מסך — EC Assist: אישור Email Address Observed
✅ Email Address Observed
ההודעה הירוקה אומרת: "The hashed email address you are sending with this conversion is valid for Enhanced Conversions."

רואים גם:

  • Matching user data from your site: john@doe.com
  • EC Mode: manual
6
אמת ב-GTM Debug Mode
אימות מתקדם

שיטה שנייה לאימות: ב-GTM Preview, לחץ על אירוע conversion בתפריט השמאלי ← לחץ על תג ה-AW-XXXXXXX ← עבור ל-Hit Details → Parameters. חפש פרמטר em — תראה את ה-Hash של האימייל.

📸 צילום מסך — GTM Debug: פרמטר em עם ה-Hash בטבלת Parameters
מה לחפש בטבלה:
• em = אימייל מוצפן (SHA256) — חייב להיות שם ✅
• ph = טלפון מוצפן — רק אם שלחת גם טלפון
• ec_mode = m (manual) — אישור שהמצב נכון
• Destination = ה-AW שלך (AW-XXXXXXX) מסומן בעיגול
💡 אם רואים em בטבלה — ה-Enhanced Conversion עובד. גוגל מקבלת את נתוני המשתמש ותתחיל לשפר את מדידת ההמרות תוך 48-72 שעות.
