שלב א׳

הגדרת תג GA4 ב-GTM

מחברים את הטריגר הקיים לאנליטיקס — 6 שלבים

♻️

אין צורך לבנות טריגר חדש. הטריגר שכבר בנית (רכישה מעל 500 ש"ח עם Some Custom Events) משמש כבסיס — רק מוסיפים עליו תג GA4.

1

יצירת תג חדש

ב-GTM נכנסים ל-Tags → New.

2

בחירת סוג התג

ב-Tag Configuration בוחרים: Google Analytics → GA4 Event.

3

Measurement ID

מזינים את קוד ה-GA4 של האתר — מתחיל ב-G-. אפשר למצוא אותו ב-GA4 תחת Admin → Data Streams.

4

Event Name

בשדה שם האירוע כותבים: high_value_purchase — באנגלית, אותיות קטנות, קו תחתון במקום רווחים.

5

קישור הטריגר

ב-Triggering בוחרים את הטריגר שכבר בנית — רכישה מעל 500 ש"ח.

6

שמירה ופרסום

לוחצים Save, ואז Submit → Publish (צד ימין למעלה). רק לאחר Publish התג חי.

שלב ב׳

יצירת קהל ה-VIP ב-GA4

הופכים את האירוע לקבוצת קהל רשמית — 6 שלבים

⏱️

צריך לחכות? האירוע high_value_purchase יופיע ב-GA4 רק לאחר שתתרחש רכישה אמיתית (או Test Event ב-DebugView). לאחר מכן תוכל לבחור אותו ביצירת הקהל.

1

כניסה לחשבון GA4

נכנסים ל-analytics.google.com ובוחרים את נכס האתר.

2

פתיחת Admin

בצד שמאל למטה לוחצים על גלגל השיניים — Admin.

3

Audiences

תחת Data Display לוחצים על Audiences.

4

קהל חדש

לוחצים על New audience → Create a custom audience.

5

בחירת האירוע

תחת תנאי השיוך מחפשים: high_value_purchase. בוחרים אותו כתנאי הכניסה לקהל.

6

שם ושמירה

נותנים שם ברור: "רוכשים מעל 500 ש"ח" ולוחצים Save. הקהל מתחיל לצבור משתמשים.

שלב ג׳

הפעלת הקהל ב-Google Ads

מתנאי מקדים עד שימוש בפועל בקמפיינים

🔗

תנאי מקדים קריטי: חשבון ה-GA4 חייב להיות מקושר ל-Google Ads. מבצעים את זה ב-GA4 תחת Admin → Product Links → Google Ads Links. לאחר הקישור, קהלי GA4 זורמים אוטומטית לגוגל אדס תוך מספר שעות.

לאחר שהקישור קיים, ב-Google Ads נכנסים ל-Tools → Audience Manager. הקהל "רוכשים מעל 500 ש"ח" יופיע שם — המקור שלו יצוין כ-Google Analytics 4.

🔵 Performance Max

Audience Signal

מוסיפים את הקהל כ-Audience Signal ב-Asset Group. זה הצעד החזק ביותר — מאותת לבינה המלאכותית של גוגל לחפש רוכשים פוטנציאליים חדשים בעלי פרופיל דומה ל-VIP שלך ביוטיוב, גוגל וג'ימייל.

📡 Audience Signal
🟢 Search Campaigns

Observation או Targeting

Observation: רואים אם לקוחות VIP מחפשים שוב — מעלים להם ביד.

Targeting: מציגים מודעות רימרקטינג ייעודיות עם מוצרי פרימיום רק לאנשים שכבר קנו בסכום גבוה.

👁 Observation
🎯 Targeting
💡

הבדל מרכזי מ-Facebook: בגוגל, קהל ה-VIP מוזרם דרך GA4 (לא ישירות מהפיקסל). היתרון — ניתן לשלב תנאים מורכבים יותר ב-GA4 (סשנים מרובים, נתוני User Properties) לפני שהמשתמש נכנס לקהל.

🏆

הצינור המלא — GTM → GA4 → Google Ads

טריגר אחד, שלוש שכבות. GTM לוכד את הרכישה, GA4 בונה קהל איכותי, וגוגל אדס מנצל אותו כ-Signal לפיתוח לקוחות חדשים ב-PMax ורימרקטינג ב-Search.
